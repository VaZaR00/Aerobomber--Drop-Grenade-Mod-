# DGM - Мод дронів з гранатами

DGM (Drone Grenade Mod) — це аддон та скриптова система для Arma 3, яка дозволяє дронам переносити, прикріплювати, від'єднувати та скидати гранати або інші сумісні боєприпаси.

Steam: https://steamcommunity.com/sharedfiles/filedetails/?id=3144481988

## Можливості

- Прикріплення, від'єднання та скидання гранат з дронів через меню дій у грі або гарячі клавіші CBA.
- Підтримка декількох типів гранат одночасно, залпового скидання (**Заряд**) та власних списків дозволених/заборонених предметів (підтримуються класи `CfgMagazines` та `CfgAmmo`).
- Серверно-авторитетна синхронізація для мультиплеєра через події CBA (без `remoteExec`, з повною підтримкою JIP).
- Налаштування через модуль Eden `DGM_Device`, кастомні модулі **Zeus Enhanced (ZEN)**, налаштування CBA Settings та SQF-функції.
- Локалізація українською, англійською та російською мовами.

## Використання

### Модулі Eden та Zeus

- **Редактор Eden:** Розмістіть модуль **Системи (F5) -> DGM -> Пристрій скиду на дрони** та синхронізуйте його з одним або декількома дронами (або вкажіть імена змінних у полі `Дрон`).
- **Zeus (з модом ZEN):** У категорії **DGM - Пристрої скиду** доступні модулі **Пристрій скиду на дрони** та **Видалити пристрій скиду**.

### SQF API

#### Додати пристрій скидання (`DGM_fnc_dropDevice`)

```sqf
[
    _drone,            // Object: об'єкт дрона
    _slotNum,          // Number (за замовч.: 1): кількість слотів для гранат
    _spawnWithGren,    // String (за замовч.: "HandGrenade"): початкова граната (та кастомний список)
    _addedItems,       // String (за замовч.: ""): додаткові дозволені класи (; , : або пробіл)
    _removedItems,     // String (за замовч.: ""): заборонені класи (; , : або пробіл)
    _allowSetCharge,   // Boolean (за замовч.: false): дозволити зміну Заряду (кількості одночасних скидів)
    _spawnTempGren,    // Boolean (за замовч.: true): створювати декоративну 3D-гранату під дроном
    _allowOnlyListed,  // Boolean (за замовч.: false): дозволити тільки предмети з кастомного/додаткового списків
    _removeChemlights, // Boolean (за замовч.: true): виключити хімсвітло та фаєри
    _removeSmokes      // Boolean (за замовч.: true): виключити димові гранати
] call DGM_fnc_dropDevice;
```

Приклад:
```sqf
[this, 2, "rhs_VOG25", "", "", true] call DGM_fnc_dropDevice;
```

#### Інші функції

- `[_drone] call DGM_fnc_removeDropDevice;` — Видаляє пристрій скидання, декоративну гранату та клієнтські меню з дрона.
- `[_drone, _slotNum] call DGM_fnc_setSlotsNumber;` — Змінює максимальну кількість слотів на дроні.
- `[_drone, _allow] call DGM_fnc_allowSetCharge;` — Вмикає або вимикає вибір Заряду на дроні.
- `[_drone, _grenClass, _num] call DGM_fnc_attachGren;` — Програмно прикріплює гранати на дрон.
- `[_drone, _grenClass, _num, _instigator] call DGM_fnc_dropGren;` — Програмно скидає гранати з дрона.

### Гарячі клавіші за замовчуванням (Керування CBA -> DGM)

- **Скинути гранату:** `Alt + G`
- **Перемкнути заряд скиду:** `Alt + C`
- **Перемкнути тип гранати:** `Alt + B`
- **Відкрити/закрити меню скидів:** *(не призначено за замовчуванням)*
